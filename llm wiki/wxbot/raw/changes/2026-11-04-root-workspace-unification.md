## 风险与回滚

风险是跨工作树合并遗漏已有修订，或仅修改 Git 分支而留下错误导入。先完成原文件、Git bundle、恢复 stash 备份，再按 Git 文本过滤规则合并并从仓库外实测导入。

回滚依靠本机备份和恢复 stash，并重新绑定目标目录的可编辑安装；不需要数据库迁移。开发 worktree 保留，不执行目录删除或服务重启。
