# 文字转微信语音

用户要求朗读、文字转语音或用指定预设说话时使用。

1. 调用 `tts_presets()` 查询网页保存的预设及当前会话的 `default_preset`。用户明确指定的名称优先；未指定时使用联系人绑定的默认预设。都没有时展示可选项，请用户选择，不猜音色。
2. 调用 `tts_generate(text="需要朗读的原文", preset="准确预设名")`。绑定过默认音色时也可省略 preset，由服务端按当前会话读取；仅有 text/preset 两个参数，收件人固定为当前微信会话。缺少文字先补齐。失效的绑定应提示重新选择，不自动换声音。
3. 工具只取预设的音色参考音频；语速、语言、情感、采样等使用网页接口默认值，**不继承预设保存的高级设置**。
4. 完整文字一次提交，最多 6000 字。服务自动按句分段，必要时再按静音位置切分音频，每条不超过 55 秒，最多 50 条，按顺序投递。不要在模型侧拆成多次生成调用。

`status=queued` 表示音频已生成并持久化排队，可回复“已生成并排队，共 N 条语音”；不能声称已送达。发送沿用 CABLE Input 播放、CABLE Output 录音和 Right Alt 长按链路。需运行 IndexTTS 网页、Butler、wxbot，并启用语音总开关及当前联系人语音模式；此技能的预设已经提供参考音，不需要另绑管理台音色资产。

`generating` 表示同一请求正在处理；`failed` 按详情说明失败；`delivery_unknown` 表示投递结果未知，提示核对微信和队列。不要自动重试、另换调用编号重发、用终端绕过授权或输出本机路径冒充已发送。只读/心跳上下文仅可查询预设。
