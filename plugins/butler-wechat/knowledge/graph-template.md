# 默认知识图谱模板

> 本文件决定新建用户 vault 的骨架与提炼口径：
> 有哪些节点目录、事实分成哪几类、索引页怎么分区、提炼时按什么口径判断。
>
> 只影响**之后新建的 vault 和新写入的事实**，不会重写已有节点。
> 事实行尾的机器可读注释（fp/kind/conf/at/src/quote）由程序固定，不在此处配置。

## 节点目录

| type   | 目录 | 说明 |
| ------ | ---- | ---- |
| person | 人物 | 具体的人：用户本人、朋友、同事、家人 |
| org    | 组织 | 公司、团队、群、机构 |
| topic  | 话题 | 长期关注的领域或兴趣 |

## 分类

| kind        | 节点小节 | 索引分类 | 提炼指引 |
| ----------- | -------- | -------- | -------- |
| profile     | 身份     | 用户信息 | 姓名、称呼、年龄、职业、所在城市、家庭与教育背景 |
| preference  | 偏好     | 喜好     | 长期稳定的口味、习惯、作息、忌讳 |
| personality | 性格     | 性格     | 说话风格、性格倾向、情绪模式 |
| goal        | 目标     | 目标     | 明确说过的打算、计划、想达成的事 |
| relation    | 关系     | 关系     | 与他人的关系、共同经历、称呼方式 |
| event       | 事件     | 经历     | 约定、发生过的事、时间地点 |
| topic       | 话题     | 关注     | 长期关注的领域、在学或在做的事 |

## 提炼规则

- 寒暄、确认、临时安排、当下的情绪和天气不算事实。
- links 只收原文里明确出现过的对象，不要为了连通而编造关系。

## 说明

- 「节点目录」里新增一行，下一次提炼就会产出这个 `subject_type`，vault 里随之多出对应目录。
- 「分类」里新增一行，下一次提炼就会产出这个 `kind`，节点里多出一个小节、索引页多出一个分区。
- 「提炼规则」会追加在内置的 6 条安全规则之后，只能加不能减：
  内置规则要求只提取用户说过的话、不推测、矛盾各写一条、助理回复不作为事实来源。
- 必须保留 `person` 节点类型与 `topic` 分类，它们分别是 `subject_type` 与 `kind` 的兜底值。
