## 审查修正与限制

独立审查发现并修复：取消排队提醒仍可能发出的竞争条件、跨目录启动时相对配置路径失效。
补充工具必填参数声明、自定义端口检查、相对业务路径解析和 Codex 专用身份说明。
切换实测又修复了空剪贴板初始序号为零被误拒绝的问题：仅对成功备份的空剪贴板允许首次写入，
写入完成后仍要求有效序号；已有内容且序号不可读时继续拒绝。保留全文校验、焦点和对象保护。
同时修正启动日志的后端名称，旧后端测试使用临时配置以避免依赖本机当前后端。

尚未发布远程 Git marketplace；原生沙箱没有经过对抗性审计。
后续升级 SDK 时需要重新核对权限字段与 MCP 桥接行为。当前闲置 worker 在后续请求时回收。

## 你需要执行

1. 审核并提交源码后上传自己的 Git 仓库；本次保留在 `codex-butler-distribution`，未提交或推送。
2. 按 [安装说明](CODEX_INSTALL.md) 在新目录初始化、独立登录，设置昵称、联系人、角色和 Skill。
3. 其他部署切换时停用 Hermes 的旧提醒、心跳和看门狗，避免重复推送；本机已按后续授权完成。
4. 旧队列和 Hermes 数据不会自动迁移；本机保留旧数据，使用新的业务数据库和收发队列。
