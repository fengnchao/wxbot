# 综合新闻与分组配置实施记录

用户确认先做综合新闻，并在 log 用户分组的新闻消息内增加类型／来源多选和每日条数。

## 交付

- `common/news_config.py`：共享分类、官方来源目录、默认值、严格校验、版本、备份与原子设置文件。
- `butler/news`：有超时和大小限制的官方 RSS 获取；24小时时间过滤、类别轮选、链接／近似标题去重；原文短摘要与链接。
- 按新闻订阅分组名单逐人调用既有 Butler 接口，保存分段投递回执；未知结果不自动重放，获取失败允许下次重新获取。
- log 新闻卡片新增多选项、每日1～10条、保存／取消、内存草稿、配置冲突提示和最近执行状态。原联系人绑定接口不变。
- 配置使用分组文件旁的 `butler_groups.news.json`，避免现有绑定保存器覆盖新增字段。当前创建默认：国内／国际／社会／财经，来源要闻导读＋分类频道，5条；原分组JSON未修改。
- 更新原 Codex 自动任务 id=9，每天北京时间09:00调用 `python -m butler.news`，保留当前线程与启用状态，取消模拟新闻生成逻辑。今天存在旧模拟标记，模块不会重复投递。
- 新模块随 butler 目录进入发布文件集合，新闻说明加入发布文档白名单；没有构建发布包或提交Git。

## 来源调研

- 中新网官方目录公开列出要闻、即时、国内、国际、社会、财经等 RSS。
- 直接读取要闻及国内 feed，均为30条，最新时间为2026-10-22上午。
- 新浪旧国内源为2018年，人民网示例为2016／2025年；36氪示例不是可解析XML。因此首批只列中新网的三个官方频道来源，不把失效来源显示成可用。

## 检查与限制

- 新Python模块、log路由、发布脚本通过 AST 语法检查；groups.js、common.js通过 Node 语法检查。
- 本次没有新增或执行自动测试，没有启动预览服务、操作浏览器或发真实微信消息。
- 未重启任何服务。用户需手动重启log，再强制刷新页面；新闻功能无需重启Butler/wxbot。
- 标题近似去重不能覆盖所有同事件的不同表述。首版直接提取原文短句，不调用模型生成摘要。
